# رساله آموزشی — وب‌اپ آفلاین (PWA)

برنامه‌ی ایستا (بدون سرور و بدون وابستگی). متن ۷۷ درس و ۵۰ بخش موضوعی (معاملات و ...) درون `data/lessons.json` است و پس از نخستین بازدید روی دستگاه ذخیره می‌شود.

## انتشار روی GitHub Pages
1. همه‌ی فایل‌های این پوشه را در ریشه‌ی یک مخزن بگذارید.
2. Settings ← Pages ← Branch: `main` / root.
3. آدرس را روی موبایل باز کنید و «افزودن به صفحه‌ی اصلی» بزنید.

> برای تست محلی: `python3 -m http.server` و بازکردن `http://localhost:8000`
> (سرویس‌ورکر روی `file://` کار نمی‌کند).

## ساختار
- `index.html` — کل رابط (HTML + CSS + JS)
- `data/lessons.json` — متن درس‌ها (بلوک‌های HTML آماده)
- `sw.js` — کش آفلاین. بعد از هر تغییر در متن/ظاهر، عدد `VERSION` را بالا ببرید.
- `manifest.webmanifest`, `icons/` — نصب به‌صورت برنامه
- `tools/build_data.py` — ساخت `lessons.json` از فایل متنی EPUB

## بازسازی داده
    python3 tools/build_data.py /مسیر/booklet_137.txt

درس ۱ تا ۷۷ از روی عنوان‌های «درس N» جدا می‌شوند. در بخش معاملات به بعد، فایل متنی عنوان درس‌ها را ندارد؛ مرزها در جدول `SECTIONS_B` بالای اسکریپت (بر اساس موضوع) تعریف شده و قابل ویرایش است.

## قلم
قلم‌ها از خود دستگاه گرفته می‌شوند (اگر «وزیرمتن» نصب باشد همان استفاده می‌شود). برای قلم دلخواه، فایل woff2 را کنار برنامه بگذارید و در `index.html` یک `@font-face` اضافه کنید.
